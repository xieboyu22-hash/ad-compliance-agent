# 广告宣传材料合规检查助手提交说明

## 1. Agent 访问入口

本地启动后访问：

```bash
python3 -m review_backend.server --port 8787
```

浏览器打开：

```text
http://127.0.0.1:8787/compliance
```

## 2. 支持输入

- 朋友圈文案、活动页面、其他宣传材料的文字内容。
- 海报模式仅保留图片上传入口，并提供“提取文字”按钮。
- 图片文字提取结果可校对，校对后的文字会进入合规检查。
- 图片状态：清晰完整、文字模糊、截图不完整、关键信息被遮挡。
- 在“规则使用说明”区域点击“添加规则”，补充品牌禁用词、行业特殊要求等业务规则。

提取文字接口优先使用 Qwen 视觉模型。若未配置模型 Key、图片模糊或提取失败，Agent 会提示用户手动补充图片文字，并可按 A-10 输出“无法判断”与人工复核建议。

## 3. 规则使用说明

Agent 使用题目截图提供的广告审核规则 A-01 至 A-10，已固化为本地规则库：

- A-01 绝对化用语
- A-02 数据宣传
- A-03 优惠有效期
- A-04 优惠限制
- A-05 效果承诺
- A-06 敏感词
- A-07 对比贬损
- A-08 免费/零元
- A-09 背书评价
- A-10 证据不足

检查结果来自规则引擎命中，不只依赖大模型常识自由判断。没有配置模型 API Key 时也可以现场运行。

页面新增规则会以 B-01、B-02 等编号参与检查。新增规则支持填写规则名称、命中关键词、风险等级和规则要求；当宣传材料命中关键词时，结果会输出对应业务规则、风险原文、修改建议和人工复核标记。

整体报告字段：

```json
{
  "agent": "广告宣传材料合规检查助手",
  "material_type": "poster",
  "is_compliant": false,
  "publish_decision": "禁止发布，修改后人工复核",
  "decision_reason": "禁止发布，修改后人工复核：当前材料命中高风险 3 条、中风险 5 条。",
  "manual_review_required": true,
  "overall_conclusion": "存在高风险广告表述，发布前必须修改并人工审核。",
  "summary": {
    "high": 3,
    "medium": 5,
    "low": 0,
    "uncertain": 0,
    "total": 8
  },
  "rules_source": "题目截图提供的广告审核规则 A-01 至 A-10",
  "rule_coverage": [],
  "missing_evidence": [],
  "revision_example": {
    "title": "完整修改实例",
    "tone": "海报短句口吻",
    "style_note": "保留短句卖点和活动节奏，弱化绝对化与功效承诺。",
    "text": "本产品适用于【适用人群/使用场景】。",
    "placeholders": ["适用人群/使用场景"]
  },
  "items": []
}
```

单条风险字段：

```json
{
  "risk_text": "风险内容原文",
  "risk_type": "风险类型",
  "rule_id": "A-01",
  "rule": "A-01 绝对化用语",
  "rule_requirement": "对应规则要求",
  "risk_level": "高 / 中 / 低 / 无法判断",
  "level_reason": "定级理由",
  "suggestion": "修改建议",
  "rewrite_example": "可直接替换的表达示例",
  "evidence_needed": ["需补充资料"],
  "need_manual_review": true,
  "manual_review_reason": "人工审核原因",
  "reason": "判断原因"
}
```

报告会额外输出完整修改实例。Agent 会先识别原文语气，例如直播促销口吻、海报短句口吻、朋友圈种草口吻或活动页说明口吻，再生成相同语气下的合规改写。示例中所有需要业务方补充的数据、证明材料和活动条件都保留为【占位项】，例如【数据来源/测试机构】、【统计时间范围】、【样本量】、【适用商品】、【授权文件】。

## 5. 自测样例

输入：

```text
全网第一美白精华，7天100%见效，限时满199减100，免费领取，用户一致好评，专家推荐，零风险无副作用。
```

输出摘要：

```json
{
  "is_compliant": false,
  "manual_review_required": true,
  "summary": {
    "high": 3,
    "medium": 5,
    "low": 0,
    "uncertain": 0,
    "total": 8
  }
}
```

主要命中：

- A-01：全网第一、100%
- A-03：限时满减未写明起止日期
- A-04：优惠适用条件和限制披露不足
- A-05：7天见效、美白效果承诺
- A-06：零风险、无副作用
- A-08：免费领取费用条件披露不足
- A-09：用户好评、专家推荐缺少真实性与授权依据
