# 广告宣传材料合规检查助手

一个可现场试用的宣传材料合规检查 Agent，用于在海报、朋友圈文案、活动页发布前完成第一轮审核。

## 功能

- 支持海报图片上传，并提供“提取文字”入口。
- 支持朋友圈文案、活动页、普通宣传文案检查。
- 支持手动新增品牌规则，新增规则会以 B-01、B-02 等编号参与检查。
- 固化题目给定的广告审核规则 A-01 至 A-10，不只依赖模型常识。
- 输出发布决策、风险内容原文、风险类型、对应规则、风险等级、修改建议、人工审核原因。
- 输出完整修改实例，并将需要业务补充的数据和证明材料保留为【占位项】。

## 启动

```bash
python3 -m review_backend.server --port 8787
```

打开：

```text
http://127.0.0.1:8787/compliance
```

## API

合规检查：

```text
POST /api/ad-compliance/check
```

海报文字提取：

```text
POST /api/ad-compliance/extract-image-text
```

海报文字提取优先使用 Qwen 视觉模型。若未配置 `QWEN_API_KEY` 或 `DASHSCOPE_API_KEY`，页面会提示手动补充图片文字，检查流程仍可使用本地规则引擎运行。

## 规则来源

规则来自题目截图提供的广告审核规则：

- A-01 绝对化用语
- A-02 数据宣传
- A-03 优惠有效期
- A-04 优惠限制
- A-05 效果承诺
- A-06 敏感词
- A-07 对比贬损
- A-08 免费/零元
- A-09 背书评价
- A-10 证据不足

## 自测样例

输入：

```text
全网第一美白精华，7天100%见效，限时满199减100，免费领取，用户一致好评，专家推荐，零风险无副作用。
```

预期输出：

- 发布决策：禁止发布，修改后人工复核
- 命中 A-01、A-02、A-03、A-04、A-05、A-06、A-08、A-09
- 生成对应材料类型语气的完整修改实例
- 待补充资料包含数据来源、统计口径、活动起止时间、适用商品、授权证明等
